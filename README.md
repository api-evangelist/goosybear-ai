Goosy Bear is an AI marketing team for small businesses and creators, offering content creation, website building, and campaign management from a single connected platform. It helps businesses generate marketing assets, automate outreach, and grow their audience efficiently with AI-driven tools and services.

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Goosy Bear: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
